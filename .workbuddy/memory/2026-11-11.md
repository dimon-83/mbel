# 2026-11-11

## 修复三处申报/审计问题

1. **时区**：`timezone()` 从仅 UTC 扩展为「UTC + 固定偏移 IANA 子集」。
   - `builtin/time.mbt` 新增 `fixed_offset_zones()`（+08:00 的 Asia/Shanghai/Chongqing/Harbin/Hong_Kong/Macau/Taipei/Singapore，+09:00 的 Asia/Tokyo/Seoul），`resolve_location` 返回 (canonical name, offset minutes)，未知名沿用 Go 措辞 `unknown time zone X`。
   - `builtin/gotime.mbt` 的 `go_parse_layout` 增第三参 `default_offset_minutes`：无显式 zone 时用 location 偏移（Go ParseInLocation 语义），字符串内数字偏移仍覆盖。
   - 带夏令时的时区（America/New_York）仍报错；子集时区在其历史 DST 年代（上海 1986-1991）与 tzdata 有界偏差，已写入 docs/expr-gap-analysis.md。
2. **Jexl MIT 许可**：THIRD_PARTY_NOTICES.md 补 TomFrost/Jexl (v2.3.0, MIT, ©2020 Tom Shawver) 条目 + covered-material 表；9 个移植文件（lexer/grammar/parser/evaluator/semantics + engine_test/lexer_test/parser_test/evaluator_test）SPDX 改 `Apache-2.0 AND MIT` 并加 `SPDX-FileCopyrightText: 2020 Tom Shawver`。
3. **WASM now() 契约**：`__moonbit_time_unstable.now` 是 `() -> i64` Unix **毫秒**，JS 必须返回 BigInt（Number 抛 TypeError、纳秒会 int64 溢出）。修正 playground/index.html（拆分 nsClock 计时 / msClock 导入）、mbel.d.ts、docs/*/wasm-embedding.md、mbel-cabi.md、tools/bindings/node-cabi.mjs、tools/check_abi.mjs（`0`→`0n`）、AGENTS.md 注释。
   - 顺带修正 docs 中「仅时刻 layout 会被拒绝」的错误说法：实测是复现 Go 的 int64 溢出回绕值。
